# Recorte e miniaturas — ilustrações

Três esquemas originais em português para explicar o recorte sem distorção, a diferença entre arquivo e miniatura circular, e a conferência do JPG exportado. Os desenhos não contêm fotos de pessoas, não são capturas do aplicativo nem demonstrações de aceitação de documentos.

- `profile-crop-1.jpg`: quadrado do arquivo e recorte circular da miniatura.
- `profile-crop-2.jpg`: preservar as proporções versus esticar o rosto.
- `profile-crop-3.jpg`: conferir miniatura, enquadramento e arquivo final.

Não há uma medida universal para todo perfil ou documento. Confirme as exigências do destinatário. Estes esquemas não avaliam identidade, semelhança de imagens geradas ou conformidade oficial.
